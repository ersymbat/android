# NutriAI

**NutriAI — Your Smart Nutrition Assistant**

## About the Project

NutriAI is a mobile application concept designed to help users learn more about nutrition and develop healthier eating habits. The project focuses on providing a simple, user-friendly, and modern mobile experience.

The application is being developed using Flutter and Dart.

## Problem Statement

Many people find it difficult to maintain healthy eating habits and organize their daily nutrition. NutriAI aims to make nutrition-related information easier to access through a convenient mobile interface.

## Target Audience

- People interested in healthy eating.
- Students and busy individuals.
- Users who want to improve their daily eating habits.

## Technologies Used

- **Flutter** — mobile application development.
- **Dart** — programming language.
- **Figma** — UI/UX design and prototyping.
- **Git and GitHub** — version control and project submission.

## Milestone 1 — MVP

The first milestone focuses on building the initial user interface and implementing basic interactions.

Planned requirements:

- Main discovery screen.
- Detail or profile screen.
- Responsive user interface.
- Reusable Flutter widgets.
- Interactive elements using `StatefulWidget` and `setState()`.
- Clean project structure.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code or Android Studio
- Android Emulator or a physical device

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd nutriAI
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
